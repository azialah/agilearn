# Grades Management — grade sheet editor

Implemented the Grades Management feature: an Excel-like editable gradebook for a
classroom, replacing the `GradesPage` stub.

## What shipped

### Data layer — `src/lib/queries/grades.ts`

- `useGradebookStructure(classroomId)` — loads grading periods, activity
  categories, and activities in render order (position, then name) as a
  `GradebookStructure`. Activities are filtered to the classroom via an inner
  join on `grading_periods`.
- `useScores(classroomId, activityIds)` — loads all scores for the classroom's
  activities as a nested `activityId -> studentId -> score` `ScoreMap`. Disabled
  until at least one activity id exists.
- CRUD mutations for periods, categories, and activities, each invalidating the
  structure (and score) query keys from `keys.grades.*`.
- `useUpsertScore` — optimistic single-cell upsert (`onConflict`
  `activity_id,student_id`) with cache snapshot, rollback on error, and
  settle-time invalidation.

All grade math is delegated to `src/lib/grading.ts` — nothing is recomputed here.

### Feature UI — `src/features/grades/`

- **GradesPage** — orchestrates the queries, weights (read from the classroom's
  lecture/laboratory split), loading skeletons, error/empty states, a guided CTA
  to create the first grading period, tabs for each period plus a Summary tab
  (animated underline + view transitions via `motion`), and the toolbar with the
  Structure panel and the mounted `ExportMenu`.
- **StructurePanel** — dialog to manage periods (name/weight/position), categories
  per component (lecture/laboratory, with a per-component weight-sum badge), and
  activities per period (name, category, max score, date, position). All
  destructive actions go through `ConfirmDialog`; deletes cascade server-side.
- **PeriodDialog / CategoryDialog / ActivityDialog** — add/edit forms reusing the
  design-system primitives, with inline validation.
- **GradeGrid** — TanStack Table with grouped headers (component → category →
  activity columns showing name + max score), a frozen sticky student-name column
  (last, first MI), computed category %, per-period component grade, overall
  component grades, and the final grade. Fully keyboard-editable score cells.
- **ScoreCell** — click / type / F2 to edit; Enter and Down commit + move down,
  Tab / Shift-Tab commit + move horizontally with row wrap, Esc cancels, arrow
  keys navigate, Backspace/Delete clears. Invalid input (non-numeric, negative,
  over max) is rejected inline with a red border and a reason chip.
- **SummaryTable** — per-student per-period lecture/laboratory grades plus overall
  lecture, laboratory, and final grades, also with a frozen student column.
- **navigation.ts** — pure helpers: `nextCell` (clamped arrow/Enter movement, Tab
  wrap), `directionForKey`, and `parseScoreInput` validation. Covered by
  `navigation.test.ts` (17 cases).

Every table scrolls horizontally on small screens while the student column stays
pinned. Students are ordered alphabetically by the existing `useStudents` query.

## Notes / deviations

- The repo root is `/home/user/grade-presenter` (no `myapp/` subdirectory); worked
  there. Only owned paths were touched.
- Row virtualization (`@tanstack/react-virtual`) was intentionally not wired in:
  the spec allows plain rows for typical class sizes, and plain rows keep the
  sticky frozen column and grouped headers reliable. Can be added later if needed.
